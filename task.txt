You are a senior full-stack engineer and UI/UX engineer. Build a complete, production-quality IPTV application called **FOX PLAYER**.

Do not create a simple demo, mockup, prototype, or AI-looking interface. Build the project as if it will be released to real users.

---

# 1. CORE CONCEPT

FOX PLAYER consists of two parts:

1. FOX PLAYER application
2. FOX PLAYER web pairing/configuration website

The app is an IPTV player.

The website is used to connect/configure an individual FOX PLAYER device by entering either:

* M3U playlist URL/details
* Xtream Codes API credentials

The app displays a QR code containing a device-specific URL.

Example:

http://localhost:3000/add-device?device-id=XXXXXXXX

The user scans this QR code with their phone/computer, enters their IPTV details on the website, and saves them.

The FOX PLAYER app can then press "Reload Playlist" and retrieve the configuration associated with that device ID.

# 5. DEVICE ID

When FOX PLAYER starts for the first time, generate a unique permanent device ID.

The device ID should be:

* exactly 8 alphanumeric characters
* uppercase
* easy to display
* unique enough for pairing
* generated securely
* stored in persistent device storage

Example:

A7K92PX4

Do NOT use a normal random ID that changes whenever the application starts.

The ID must remain the same across normal app restarts.

Most importantly:

## REINSTALL REQUIREMENT

If technically possible on the target platform, the device ID must survive application uninstall/reinstall.

Do not simply store the ID in ordinary application preferences if that storage is destroyed during uninstall.

Use the strongest platform-appropriate persistent identifier/storage mechanism available.

If the operating system makes a true uninstall-surviving identifier impossible, implement the most reliable platform-supported approach and document the limitation rather than pretending it is guaranteed.

Never use a MAC address directly.

Do not expose sensitive hardware identifiers.

The displayed 8-character device ID is the pairing identifier.
